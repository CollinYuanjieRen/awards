Let $\delta>0$ and $k\geq 3$. Is it true that there exists $m\geq 1$ (depending only on $\delta$ and $k$) such that, for all large $N$, if $A,B\subseteq \{1,\ldots,N\}$ with $\lvert A\rvert \geq \delta N$ and $\lvert B\rvert \geq m$ then there is a non-trivial $k$-term arithmetic progression in $A$ whose common difference is in $B-B$?
#1185

[Er80,p.92]
additive combinatorics
 | 
arithmetic progressions
In 
[Er80]
 Erdős attributes this problem to him and Mauldin, motivated by 'a problem in measure theory'. 
This is false already at $k=3$. A set $S\subseteq \mathbb{N}$ is called $k$-intersective if every subset of $\mathbb{N}$ with positive density contains an arithmetic progression of length $k+1$ whose difference is in $S$. To disprove this it suffices to give an infinite set $B$ such that $B-B$ is not $2$-intersective, which was provided by Furstenberg 
[Fu81]
.
