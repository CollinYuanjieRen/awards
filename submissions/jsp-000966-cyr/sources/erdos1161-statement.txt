SOLVED This has been resolved in some other way than a proof or disproof. Let $f_k(n)$ count the number of elements of $S_n$ of order $k$. For which values of $k$ will $f_k(n)$ be maximal? #1161 :  [Va99,5.72] group theory Beker  [Be25d]  proved that\[\max_{k\geq 1} f_k(n)\sim (n-1)!,\]and that if $n$ is sufficiently large and $f_k(n)\geq (n-1)!$ then $[1,\ldots,n-k]\mid k$. Furthermore, for all large $n$, $f_k(n)=(n-1)!$ if and only if $k\geq 1$ is minimal such that\[[1,\ldots,n-k]\mid k.\] Additional thanks to : Quanyu Tang
